# Canan Rabia Bodur | Kişisel Tanıtım Sitesi

Sosyal hizmet öğrencisi Canan Rabia Bodur'un kişisel tanıtım ve blog sayfası.
Site, ders ödevi kapsamında Claude Code desteğiyle hazırlanmış ve GitHub Pages ile yayınlanmıştır.

## İçerik

- Hakkımda
- Sosyal hizmet (tanım, temel ilkeler, çalışma süreci)
- Tezim (araştırma süreci)
- Blog (staj, rapor ve tez yazıları, etikete göre filtreleme)
- Neden bu siteyi kurdum?
- İletişim
- Açık / koyu tema düğmesi

## Dosyalar

- `index.html`: Sitenin ana sayfası (HTML, CSS ve JavaScript tek dosyada)
- `README.md`: Deponun açıklaması
